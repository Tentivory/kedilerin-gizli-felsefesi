# Kedilerin Gizli Felsefesi

## Bilimsel Bir Devrim (Gerçekten)

Bu repository, kedilerin aslında yüzyıllardır gizli tutulan derin felsefi düşüncelerini ortaya çıkaran **dünyanın ilk ve tek** bilimsel aracıdır. 

Miyavlar rastgele sesler değildir. Onlar, varoluşun özünü sorgulayan antik bilgelerin fısıltılarıdır. Bu kod, o fısıltıları Türkçe'ye çevirir. 

### Nasıl Çalışır?

1. Python 3 yüklü olsun (yoksa kedi üzülür).
2. Çalıştır:
   ```bash
   python miyav_felsefe.py
   ```
3. Kediye miyav de veya sadece Enter'a bas.
4. Derin düşünceleri oku ve hayata bakışını değiştir.

### Uyarı

Bu program çok güçlüdür. Felsefe dozunu aşarsanız varoluşsal kriz yaşayabilirsiniz. Sorumluluk size aittir. 

### Katkı

Pull request'ler kabul edilir, ama sadece kediler gönderebilir. İnsanların katkısı şüpheli karşılanır.
